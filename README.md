# ThreadCo – E-Commerce Website 👕

A modern, responsive streetwear e-commerce website built to provide a clean and engaging online shopping experience.
ThreadCo is a fashion-focused e-commerce platform designed around limited streetwear drops, oversized apparel, hoodies, cargo pants, caps, and other fashion products. The project demonstrates core front-end e-commerce functionality, including product browsing, product details, shopping cart management, responsive design, and a modern user interface.

# 🚀 Live Project

ThreadCo – Wear the Code. Live the Street.

Visit the Live Website: https://e-commerce-website-sage-mu-70.vercel.app

Built with using HTML, CSS, and JavaScript.


# 💻 Project Overview
ThreadCo follows a modern streetwear brand concept:

Wear the Code. Live the Street.
The platform presents limited fashion drops and allows users to explore products and interact with a shopping cart interface.

The homepage highlights:

• New product drops

• Featured products

• Product categories

• Product pricing and discounts

• Bestseller products

• Product ratings

• Brand values

• Early access newsletter section

•Shopping cart functionality

The current storefront includes products such as the Oversized Drop Tee Vol.3, Street Hoodie – Olive, Utility Cargo – Beige, and TC 6-Panel Cap, with pricing, discounts, and product-detail navigation.
